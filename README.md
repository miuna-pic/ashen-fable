# 灰烬寓言 · Ashen Fable

## 序章：无主祭坛

王座空了。烛廷把骨白的人偶送进林中，荆廷让铜绿的遗偶自树根苏醒。森林不承认两廷的誓言；它只记得谁从哪里离开。

《灰烬寓言》是一个 5×5 的原创黑暗童话棋类游戏原型。首局支持与人偶对弈或同屏双人，浏览器内无需账号。选己方棋子，看可落点；再选落点预览回声，重复点落点或按「落子」确认。键盘可用 Tab 进入棋盘、方向键移动焦点、Enter 确认、Esc 取消。

### 回声规则

- 无名王任意方向一步；缄默狼走直线一至两格；缝眼修女走斜线一至两格。不能穿越棋子，可落在对方棋子所在格吃掉它。
- 每手在出发格留下回声，连同邻接的上下左右格，但不包括朝你前进方向的格子。例如 D2 → D3 会标记 D2、C2、E2、D1。
- 对手完整走一手后，上道回声才落下：标记区内的双方棋子同时被移除。直接吃王立即胜利；否则先结算回声，再判王座。
- 让一枚己方棋子占住中央 C3，撑过敌方一手和回声即可获胜。双王同亡、三次同局面或满四十手未决胜负为和，无合法落点则败。

### 美术与交互

原创「余烬祭坛」把薄雾剪影、断裂星盘、程序绘制的石纹和手工组合的微型雕像叠成一处林中遗址。骨白和铜绿区分两廷；绿色菱形表示落点、朱红裂纹表示将结算的回声，虚线描边预告下一道回声。声音默认关闭；尊重系统减少动态设置。WebGL 不可用时可使用有同等棋规的平面棋盘。

### 开发

使用 Node.js 20.19+ 或 22.12+。

```sh
npm ci
npm run dev
npm test
npm run build
```

部署构建后的 `dist/` 即可。不需要后端。棋规和人偶对弈独立于 Three.js 渲染，两种前端共用同一状态；本地字体子集的许可证在 `public/`。
